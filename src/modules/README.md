# Backend feature modules

Start at a feature README or its matching `.module.ts` file.

| Folder / Nest module | Responsibility |
| --- | --- |
| [authentication](authentication/README.md) | Email/password and Google sign-in, access tokens, refresh sessions and password hashing. |
| [user-accounts](user-accounts/README.md) | Profiles, profile setup, referrals, account recovery and deletion. |
| [personal-wellness](personal-wellness/README.md) | Water intake, menstrual tracking, medicine schedules and doses, activity targets and data export. |
| [care-directory](care-directory/README.md) | Hospitals, doctors, labs, pharmacies, medicine information, affiliations and correction requests. |
| [health-resources](health-resources/README.md) | Health articles, article categories, blood-bank discovery and their shared CSV/workbook import workflow. |
| [meditation-library](meditation-library/README.md) | Published meditation videos and guided practices. |
| [home-dashboard](home-dashboard/README.md) | Home content, care discovery and weather integration. |
| [jeeva-assistant](jeeva-assistant/README.md) | AI conversations, application guidance, safety rules and optional saved-health context. |
| [administration](administration/README.md) | Protected administrator APIs, content management, portal assets and audit logs. |
| [system-health](system-health/README.md) | Operational API liveness and database readiness checks. |
| [system-status](system-status/README.md) | Public backend status page and bounded request-activity diagnostics. |
